# Живые локации CatWar

Юзерскрипт, который заменяет статичные фоны локаций в CatWar на анимированные: течёт вода, качаются трава и листья, мерцают кристаллы, летают светлячки, по пещерам гуляет свет.

## Что здесь

- `catwar-anim.user.js`: сам юзерскрипт для Tampermonkey
- `bg/`: готовые анимации, имя файла = номер фона в игре
- `generator/`: код, которым они сделаны. `locanim.py` эффекты, `run.py` запуск, `configs/` настройки каждой локации
